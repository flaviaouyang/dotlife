# AGENTS.md

Instructions for coding agents working on dotlife. Claude Code reads this through `CLAUDE.md`.

dotlife is a small, open-source life dashboard. Its core is a plain-file data format (CSV and Markdown in the user's own repo). A stdlib-only validator checks the files, and a Streamlit dashboard reads only that format. Agent skills fill the format from a user's sources. See `README.md`.

## Layout

The project is early, so most of these don't exist yet.

- `FORMAT.md`: the data format spec. It is the source of truth for files, columns, units and rules.
- `config.toml`: every number and threshold. Code reads it and never hard-codes a value.
- `validate.py`: checks data files against the format. Standard library only.
- `sample/`: made-up data generated by `scripts/make_sample.py`. Don't edit it by hand.
- `scripts/`: shared helpers and source importers. Standard library only.
- `dashboard/`: Streamlit app. Entry point `streamlit_app.py`, pages in `app_pages/` via `st.navigation`, theme in `.streamlit/config.toml`. Use the `developing-with-streamlit` skill when changing it.
- `.agents/skills/`: the `setup-sources` and `sync` skills (`.claude/skills` links here). Write them for any agent: name capabilities ("a health connector"), not one vendor's tools.
- `docs/sources/`: one guide per data source. People follow them, and the skills read them, so keep them accurate for both.

## Rules

- **Missing data stays missing.** Never estimate, interpolate or invent a value. Report gaps.
- **Scripts over AI calls.** Anything that can be scripted is a script.
- **Settings in `config.toml`**, not in code or prose.
- **Weeks** run Monday to Sunday in the user's local time zone (`zoneinfo`). **Sleep** counts toward the wake date. Clock-time maths uses minutes after 18:00.
- **No real personal data** anywhere in the repo: not in sample data, examples, tests, screenshots or docs. Everything is made up.
- Keep it small. Prefer fewer files and plain code over abstractions.

## Conventions

- Python 3.11+. Scripts and `validate.py` use only the standard library. The dashboard's dependencies are managed with uv in `pyproject.toml` (`uv add <pkg>`).
- `make format` runs ruff and pymarkdown. Write Markdown with blank lines around headings and lists, one paragraph per line.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/). Keep them small, with formatting changes in their own commit.
